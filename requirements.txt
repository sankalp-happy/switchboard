# Runtime dependencies for the gateway. Test-only packages live in
# requirements-dev.txt so the production image does not ship a test runner.
#
# Versions are pinned exactly. This is deployable application code, not a
# library, so reproducibility beats flexibility: a contributor's install
# resolves to the same versions CI tested against. Dependabot (see
# .github/dependabot.yml) proposes the upgrades.
